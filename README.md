# LinkSentry 🔐

A Python-based URL security analysis
tool designed to identify suspicious
URL patterns and potential phishing indicators.

## Project Overview

LinkSentry analyzes URLs using
rule-based security checks and provides
a risk assessment report.

## Planned Features

- URL validation
- HTTPS detection
- Suspicious keyword detection
- IP-based URL detection
- Risk scoring system
- Security analysis dashboard

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Pytest

## Development Status

🚧 Currently under development.

## Disclaimer

LinkSentry is an educational security
analysis project. It does not guarantee
that a URL is safe or malicious.
